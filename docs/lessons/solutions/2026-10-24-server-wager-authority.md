# Answer — server-side wager authority

Browser code runs on the user's device and can be changed or bypassed; a crafted HTTP request can reach the endpoint without clicking Deal. The server must validate the request's shape, current phase/revision, integer half-chip stake, positivity, evenness for whole-chip wagers, and affordability from its own session balance before mutating the bankroll or shoe. The client cannot authoritatively report the balance or outcome.
