### Work through the interpretation

First compute each difference d = greedy mean - threshold mean. For seed 7: -0.08295 - (-0.08195) = **-0.00100**. Across all five equally sized runs, average difference = -0.06923 - (-0.07970) = **+0.01047** reward units per hand. This difference is not profit: the Q-learning mean itself is negative.

The earlier fixed-setting SARSA mean was -0.06249. Q-learning's observed mean is 0.00674 lower in these experiments. That does not establish an algorithm ranking: five seeds are few, training paths differ, and we have no untouched final comparison or uncertainty analysis of that difference. Shared seed labels do not imply identical hands across different policies. Do not choose the most favorable run or retune using these data and call the same results independent validation.

### Reproduce from the project root

```sh
for seed in 7 19 42 101 2026; do
  python3 -m foundations.q_learning --episodes 50000 --eval-episodes 20000 --seed "$seed" --eval-seed "$((1000000 + seed))" --epsilon 0.1 --alpha 0.1 --output "/tmp/q-$seed.json"
done
```

The loop changes seeds and output paths only. Each invocation retrains from an empty Q table, freezes it, and evaluates three policies. To calculate the mean yourself, extract each report's `evaluation` row whose `policy` is `greedy`, sum its `mean_return` values, and divide by five. For sample SD, square each deviation from that mean, sum, divide by four, then take the square root; Python's `statistics.stdev` performs those steps.
