# 12 October: one environment, different interfaces

## Prerequisites and intuition

The environment owns game rules and private state. An observation contains only information the player may see. An action is an intent such as hit; the environment decides whether it is legal. An adapter translates between a user interface and that environment.

The new [terminal adapter](../../public_game/play.py) lets you play the public-rule Python engine, including split and double, without writing rules a second time. It reads only `session.view()` for presentation, so the hidden dealer card appears as `??` during play. This is a local prototype with virtual chips, not a published website or a trained coach.

## Run it

From the repository root:

```sh
python3 -m public_game.play --seed 7
```

Type `deal 10`, then `hit`, `stand`, `double` or `split` when advertised. Type `quit` to exit. Wagers are whole chips; the internal engine still uses half-chip integers. Starting balance is100 chips. EOF or Ctrl-C also exits. A new process starts a new seeded session; there is no persistence.

## Coding steps

1. Parse user text into a command and, for deal, an integer wager.
2. Convert chips to internal units: units=2×chips. A wager10 becomes20 units.
3. Submit the intent with the current revision. The engine still validates phase, funds and legality.
4. Format the resulting visible snapshot. All split hands are listed; an arrow marks the active one.
5. Display completed profit and normalized profit only after settlement. Reject malformed/illegal commands without changing the session.

No random draws, payout rules or dealer strategy live in this adapter. A future browser should follow the same separation, with additional transport/session protection. This terminal process is single-user and single-threaded; it is not an API security implementation.

## Worked experiment and RL connection

Seed7, `deal 10` then `stand` ends with profit-10 chips and normalized result-1. Internally, balance starts200 units, deal reserves20, loss credits0: final180 units=90 chips. Reward for a future episode is P/b=-20/20=-1. Changing display units to chips does not change the ratio: -10/10=-1.

A policy could later supply action intents where a person currently types. It must use the visible observation and legal action list, and must be trained/evaluated for these public rules. Existing Foundations hit/stand policies are not compatible full-game agents.
