The core idea is to estimate how good a position is by averaging the returns that follow it. We keep the policy fixed: hit below 17, stand otherwise. The value table learns; the policy does not improve yet.

## One update, explained

A state has had two sample returns, +1 and -1. Its count is 2 and its estimated value is 0. A third hand ends with +1:

```text
new count = 3
new value = old value + (new return - old value) / new count
          = 0 + (1 - 0) / 3
          = 1/3
```

First-visit Monte Carlo updates a position once per completed hand, using the return after its earliest occurrence. The lesson explains returns, the incremental mean, episode recording, and the difference between prediction and control, with separate [worked answers](../lessons/solutions/02-monte-carlo-prediction.md).

## Measured results

For seed 7, threshold 17, and 10,000 hands: **4,009 wins, 4,922 losses, 1,069 pushes**, mean return **-0.0913** units/hand. That matches the previous fixed-policy baseline, as it should: value prediction did not change the actions.

| Position | Estimated value | First-visit samples |
|---|---:|---:|
| Hard 16 vs 10 | -0.6167 | 407 |
| Hard 20 vs 10 | +0.4221 | 507 |
| Soft 13 vs 2 | -0.4286 | 14 |

For five separate 10,000-hand runs of the same threshold-17 policy:

| Seed | Mean return per hand |
|---|---:|
| 7 | -0.0913 |
| 19 | -0.0803 |
| 42 | -0.0627 |
| 101 | -0.0894 |
| 2026 | -0.0839 |

In the 100,000-hand seed-7 run, mean return was -0.08277. Soft 13 vs 2 had 90 samples and an estimate of -0.1000; it was still much rarer than hard 20 vs 10 (4,927 samples). Increasing the sample count does not make every finite-sample estimate move monotonically toward its true value.

These are descriptive samples, not confidence intervals or proof of optimal play. The 100,000-hand seed-7 run extends the same seeded stream, so it is not an independent replication of the 10,000-hand seed-7 run. The threshold-18 example in the saved record uses a different fixed policy; do not pool its state-value table with threshold 17. Value is expected return, not win probability.
